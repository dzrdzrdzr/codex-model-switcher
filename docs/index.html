Codex DeepSeek Switcher

Switch OpenAI Codex in VS Code—including Codex profiles authenticated through ChatGPT—between OpenAI and DeepSeek without mixing local, Remote SSH, or provider credentials.

What problem does it solve?

Use DeepSeek with Codex

Connect Codex directly to DeepSeek's Responses API from one VS Code environment.

Keep ChatGPT login intact

The normal OpenAI or ChatGPT-authenticated Codex profile stays separate from the DeepSeek API-key profile.

Isolate Remote SSH hosts

Local VS Code and every remote extension host select their provider independently.

Direct provider configuration

model_provider = "deepseek"

[model_providers.deepseek]
base_url = "https://api.deepseek.com/"
wire_api = "responses"

No MoonBridge, localhost relay, or protocol disguise is required.

Frequently asked questions

How can I use DeepSeek with OpenAI Codex in VS Code?

Install the VSIX and run Codex Source: Use DeepSeek Direct.

Can I keep using my ChatGPT-authenticated Codex profile?

Yes. The extension leaves the normal .codex profile intact and writes DeepSeek configuration to .codex-vscode-deepseek.

Does it work with Codex CLI over Remote SSH?

Yes. Install the extension on the remote extension host; each host has its own mode, launcher, and isolated profile.
