# Codex DeepSeek Switcher 0.2.8

Switch OpenAI and DeepSeek in VS Code without manually rewriting the normal Codex profile. Windows local and Linux Remote SSH environments use separate provider profiles; windows sharing the same OS account/home share the selected mode. Reload the window to apply a switch.

## Installation

Download `codex-local-model-switcher-0.2.8.vsix` below and use **Extensions: Install from VSIX...**. For Remote SSH, install it in the remote extension host. Save active work before switching.

This release uses the existing Marketplace identity `dzr.codex-local-model-switcher`. Disable the legacy `hanzaidao.codex-local-model-switcher` if it is also installed; do not delete `.codex` or any of your saved profiles.

The Marketplace update is a separate publishing operation. This GitHub release does not itself prove that the Marketplace version or GitHub Pages site has updated.

- Verified package identity, version, runtime-file allowlist and SHA-256 checks. Source and website archives are included.

## Validation boundary

CI compiles and executes the actual Windows launcher against a harmless probe executable and verifies configuration selection, arguments, stdin, child exit codes and switching back. Linux tests use disposable homes and a mock Codex. These are not live OpenAI/DeepSeek requests or full VS Code UI certification. No user's credentials, private code or running work environment were accessed. API use still requires the user's own credentials and can incur provider charges.

The extension stores the DeepSeek key in its isolated profile; it does not encrypt that file. Keep profile files/backups private. This remains an independent community project, not an official OpenAI, DeepSeek or Microsoft extension.
